# GripLog

Offline-first workout tracker for iOS and Android.

## Repository layout

| Path            | What it is                              |
| --------------- | --------------------------------------- |
| `apps/mobile`   | Expo app (SDK 57, React Native 0.86)    |
| `packages/core` | Pure training logic shared by every app |

## Getting started

```bash
npm install
npm run mobile
```

## Checks

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
```
